# SKT Conta görsel barındırma

Bu depo SKT Conta ürün görsellerinin Excel satırlarıyla eşleşmesini sağlamak için hazırlanmıştır.

## Görselleri ekleme
1. `_upload` klasörüne `sktconta_images.zip.part01` ve `sktconta_images.zip.part02` dosyalarını yükleyin (Add file → Upload files).
2. GitHub Actions, parçaları birleştirip ZIP içindeki resimleri `images/` klasörüne aktarır.
3. Bağlantıların giriş yapmadan açılması için bu deponun **Public** görünürlükte olması gerekir (Settings → General → Danger Zone → Change repository visibility). Kaynak kodu içeren başka depoları public yapmayın.

Örnek resim URL'si (depo public ve yükleme tamamlandığında):
https://raw.githubusercontent.com/metin71/excel-projeleri/main/images/sktconta_image12.png

NOT: Depo private olduğu veya yükleme tamamlanmadığı sürece bu URL'ler herkese açık çalışmaz.
